# Full Stack Open  

Solutions and projects completed as part of the University of Helsinki Full Stack Open course.

## Course

Full Stack Open is a web development course covering:

- JavaScript
- React
- Node.js
- Express
- REST APIs
- MongoDB
- GraphQL
- TypeScript
- React Native
- CI/CD
- Containers
- Relational databases
- Next.js

## Repository structure

Each course part is contained in its own directory. When an exercise continues in a later part, that part gets its own copy and the earlier version is left unchanged. `courseinfo` from part 1 is copied into part 2 for that reason.
