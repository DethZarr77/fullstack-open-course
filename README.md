# Full Stack Open  

Solutions and projects completed as part of the University of Helsinki Full Stack Open course.

## Course

Full Stack Open is a web development course covering:

- JavaScript
- React
- Node.js
- Express
- REST APIs
- MongoDB
- GraphQL
- TypeScript
- React Native
- CI/CD
- Containers
- Relational databases
- Next.js
